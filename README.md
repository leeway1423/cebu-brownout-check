# Cebu Brownout Check (unofficial)

Rotational brownout lookup by barangay for Visayan Electric areas in Metro Cebu.

- Data source: Visayan Electric rotation schedule map — https://fyi.aboitizpower.com
- `data.json` is refreshed automatically every hour (8 AM–9 PM, Philippine time).
- Unofficial community service. Not affiliated with Visayan Electric, MECO or any government agency.
